# tech-farm
Urban Harvest 🌱
A lightweight, community-driven urban farming platform with transparent contribution tracking and fair reward distribution. Built as an MVP for real-world pilot testing.

Features

Public Landing Page — explains the project with clear value proposition and call-to-action
Participant Dashboard — log contributions, track points, view activity history
Points System — 1 hour = 10 points, harvest = 20 bonus points, weekly consistency = 10 bonus points
Transparency Page — public leaderboard, total contributions, recent harvests
Harvest Tracking — log crops, quantities, and contributors
Admin Panel — manage participants, adjust points, log harvests, toggle visibility
Tech Stack

Frontend: Next.js 16 (App Router) + Tailwind CSS 4
Backend: Supabase (PostgreSQL + Auth + RLS)
Auth: Email magic link (passwordless)
Deployment: Vercel-ready
